# Eden-Fork-Nextendo
A project to fork eden nintendo switch emulator to nextendo server (like citron and riujinx got forked), the idea is to make the user able to switch to different network configurations from the network interface with a submenu, project started because i think that eden is one of the best nintendo switch emulators at the moment

this project starts whit the idea of forking eden to nextendo, given trhe other succesful project, it starded cause my personal favourite emulator was yuzu with its successor eden, so i wanted to fork it to the nextendo servers to be able to play directly from eden
